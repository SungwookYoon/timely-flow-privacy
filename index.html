Timely Flow 개인정보처리방침

시행일: 2026년 11월 10일

처리하는 정보와 목적

Timely Flow는 사용자가 입력한 주제, 프롬프트, 선택한 모델, 작업 단계, 예약 설정, TimelyAI 답변, 대화 URL, 실행 시각과 오류 기록을 처리합니다. 이는 사용자가 요청한 모델별 조사, 답변 취합, 보고서 생성 및 예약 실행을 위한 것입니다. TimelyAI 화면의 버튼과 입력창 구조를 읽어 페이지를 조작합니다.

저장과 삭제

설정, 모델 목록, 작업 초안 및 최근 20개 실행 기록은 Chrome 확장 프로그램의 로컬 저장소에 저장합니다. 최근 20개를 초과하면 오래된 기록이 대체됩니다. 확장 프로그램을 제거하면 해당 확장 프로그램의 로컬 데이터가 삭제됩니다. 사용자가 내려받은 파일 및 TimelyAI에 저장된 대화는 별도로 삭제해야 합니다. Chrome의 저장 한도를 따릅니다.

외부 전송 및 제3자 서비스

사용자가 실행한 질문과 이전 단계에서 참조하도록 선택한 답변은 로그인된 TimelyAI 화면을 통해 선택한 모델에 전달됩니다. TimelyAI와 연결된 모델 제공업체의 데이터 처리는 각 서비스의 정책에 따릅니다. 개발자는 별도 서버로 이 정보를 수집하지 않으며 판매, 광고, 추적 또는 신용평가에 사용하지 않습니다. 자동 오류 전송 및 광고 분석 SDK는 포함하지 않습니다.

인증 정보

브라우저의 기존 로그인 상태를 이용하며 세션키, 비밀번호 또는 쿠키를 확장 프로그램이 직접 읽거나 저장하도록 구현하지 않습니다. 사용자는 프롬프트에 불필요한 개인정보나 기밀을 포함하지 않아야 합니다.

권한과 진단

TimelyAI 도메인 접근은 해당 페이지의 읽기·입력에, sidePanel은 사이드바 표시에, storage는 로컬 저장에, alarms는 반복 실행에, scripting은 페이지 연결 스크립트 주입에 사용합니다. 현장 스모크 보고서는 사용자가 실행하며 모델명, 화면 경로, 버튼 개수와 표시 상태 등을 표시합니다. 해당 보고서를 지원 담당자에게 공유할지는 사용자가 결정합니다.

제한적 사용

사용자 데이터는 확장 프로그램에 명시된 단일 목적을 위해서만 처리합니다. Chrome Web Store 사용자 데이터 정책의 제한적 사용 요구사항을 준수합니다.
